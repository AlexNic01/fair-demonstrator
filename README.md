# FAIR case record: demonstrator

Landing page, HDF5 viewer link and HTML viewer of a **demonstrator** case record: a real fixed-bed measurement on
the TREx rig (particle A) combined on purpose with a packed bed, mesh and CFD computed for a different particle
(particle B, a generic hollow cylinder). Measurement and simulation do not belong together; the case shows the
workflow and the interface, not physically consistent data.

- `index.html`: landing page (GitHub Pages)
- `report.html`: interactive HTML viewer
- `data/TREX_DEMO_2026-10-06_001.h5`: the case record, opened in myHDF5 from the landing page
